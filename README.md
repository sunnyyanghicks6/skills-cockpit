# Skills Cockpit

A live, searchable catalog of the Claude Code skills I actually use — organized by
usage tier (commonly used / should use / never used) and the kind of project each
serves. Built from my own skill library and usage data.

**Live:** https://sunnyyanghicks6.github.io/skills-cockpit/

This is the public, scrubbed build (no client or internal data). Generated by a small
Python tool that reads my local skill files and session stats, then emits a single
self-contained HTML page.
